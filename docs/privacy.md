# Privacy Policy for Iruka Calendar

Last updated: 2026-09-15

Iruka Calendar is a personal, self-hosted integration operated for its owner's
use. It accesses Google Calendar only after the Google account owner grants
permission through Google's OAuth consent screen.

## Data accessed

The application may read calendar lists and calendar events so that the owner
can ask about schedules. It may create and manage only calendar events created
through the application when that permission is granted.

## Storage and sharing

OAuth credentials and derived application state are kept in the owner's
self-hosted environment. They are not committed to public source repositories.
Google Calendar data is not sold, used for advertising, or shared with third
parties.

## Revocation and deletion

The account owner can revoke access at any time from the Google Account
third-party connections page. Local OAuth credentials and derived application
state can then be deleted from the self-hosted Iruka / Onyx deployment.

## Contact

Questions about this integration can be submitted through the repository owner
on GitHub.
